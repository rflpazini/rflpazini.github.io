## Projetos em Destaque

### Projetos Docker Captain
**Contribuições para Ecossistema Docker**  
Engenheiro Backend • Ativo  
Melhores práticas Docker, padrões de containerização e educação da comunidade. Liderando workshops e criando conteúdo para a comunidade Docker.

**Integrações LocalStack**  
Go & Java • Ativo  
Criando exemplos e documentação para LocalStack, focando em mocking de serviços AWS para ambientes de desenvolvimento local.

**Exemplos Docker Buildx**  
Go 1.23+ & Java 21 • Ativo  
Exemplos de builds multi-plataforma mostrando capacidades modernas do Docker Buildx para pipelines eficientes de CI/CD.

### SaaS & Aplicações Web
**James 3D SaaS**  
Go & AWS • Ativo  
Sistema de gestão de fazenda para operações de impressão 3D. Rastreia inventário, otimiza filas de impressão e gerencia pedidos de clientes.

**ModMini3D**  
Design 3D • Ativo  
Marca para miniaturas articuladas customizadas. Especializada em modelos de personagens detalhados para jogos e colecionáveis.

### IoT & Hardware
**Botão de Pânico ESP32**  
AWS Lambda & WhatsApp • Ativo  
Dispositivo IoT que envia alertas de emergência via WhatsApp usando arquitetura serverless AWS e IoT Core.

**Rack Orange Pi 5 Plus**  
Design de Hardware • Ativo  
Solução customizada de rack mount de 10 polegadas para computadores single-board Orange Pi, otimizada para edge computing.

### Desenvolvimento de APIs
**App iOS DePé**  
Swift & NFC • Ativo  
App iOS de alarme com integração NFC para experiências de despertar seamless.

**MVP Healthtech**  
AWS Lambda & IA • Ativo  
Sistema de ingestão de exames médicos usando IA para processamento automatizado de documentos e extração de dados de saúde.

**API Gateway Go**  
Go & MCP • Ativo  
Gateway de API REST com integração MCP (Message Control Protocol), apresentando implementação Swagger PetStore.
